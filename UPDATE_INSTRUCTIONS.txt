DelvUI Input Guard 0.1.1.0 update

This update fixes:
- DelvUI version/runtime detection
- DelvUI mouse reactions through overlapping ImGui windows
- incompatibility caused by relying on an outdated HudElement base type
- false/ambiguous detection caused by ImGui WantCaptureMouse

UPDATE STEPS

1. Extract this ZIP.
2. Open your GitHub repository:
   https://github.com/Surlako/Delvui-Input-Guard
3. Choose Add file -> Upload files.
4. Upload all seven project files from this ZIP to the repository root.
5. Commit the replacements.
6. Open Actions -> Build and publish plugin -> Run workflow.
7. Wait for the green checkmark and confirm release v0.1.1.0 exists.
8. Open /xlplugins in FFXIV and update DelvUI Input Guard.
9. Reload the plugin or restart the game.
10. Open /dig and verify:
    - DelvUI installed: Yes
    - DelvUI loaded: Yes
    - DelvUI runtime patches attached: Yes
    - Window overlap tracker ready: Yes

The .github workflow does not need to be uploaded again.
